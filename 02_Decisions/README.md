# Decisions

This folder stores Architecture Decision Records (ADRs) — notes about *why* specific choices were made.

Use a new file per decision, named by date and topic, e.g. `2026-05-03-use-ctypes-over-sdk.md`.

Each ADR should answer:
- **What** was decided
- **Why** (constraints, tradeoffs, alternatives considered)
- **Consequences** (what this means going forward)
