# 2026-05-12 — Window resize fix + dark title bar theming

## What shipped

### Window resize (Restrain beta feedback)

**Investigation:** Restrain reported the window snapping back and edges not being draggable. Root cause: `frameless=True` strips the Win32 frame including resize handles. Three Option B approaches were tried and eliminated:
1. React `onMouseDown` on fixed CSS hit zones — OS intercepts edge clicks before WebView2 sees them.
2. `document.addEventListener("mousedown", ..., true)` capture phase — same: OS eats the event before JS runs.
3. WM_NCHITTEST WNDPROC subclass — hook installs correctly (confirmed via log) and cursor changes, but WebView2's full-client-area input capture prevents the OS from acting on the returned HT codes.

**Decision: Option A.** Dropped `frameless=True`, removed `easy_drag=False` and `DRAG_REGION_SELECTOR` from `main.py`. Native chrome provides edge-drag resize, window position persistence, and OS snap-to-edge. ADR written at `02_Decisions/2026-05-11-window-resize.md`.

**Frontend cleanup:** removed `<Titlebar>` from `main.jsx` render (native chrome handles min/max/close/drag); removed `ResizeHandles` component, `resizeWindowEdge` API wrapper, and all Option B bridge code. Net change to `bridge.py` and `shared.jsx` vs the previous commit: zero (additions and removals balanced).

### Dark title bar theming

Used Win32 DWM APIs to match the native title bar to the app's dark theme:
- `DWMWA_USE_IMMERSIVE_DARK_MODE = 20` — dark chrome (Windows 10 21H1+)
- `DWMWA_CAPTION_COLOR = 35` — background `#050505` matching `--titlebar` CSS var
- `DWMWA_TEXT_COLOR = 36` — text `#f0f0e8` matching `--titlebar-text` CSS var

Applied via a daemon thread in `main.py` (`_titlebar_theme_worker`) that polls until `FindWindowW("Neon White Tools")` returns a visible HWND, then calls `DwmSetWindowAttribute` for each attribute. Graceful degradation: each call wrapped in try/except so older Windows versions silently skip unsupported attributes.

Helper `_rgb_to_colorref(hex_color)` converts `#RRGGBB` → Win32 `COLORREF` (BGR byte order).
