# Session 2026-05-06 — M3 Polish

## What landed

### M3 core (leaderboard pages + Steam runtime)
- **bridge.py**: `init_steam` (calls `steam_api.init_steam`, starts 100ms `RunCallbacks` daemon, saves dll_path), `get_steam_status`, `pick_dll_file`, `pick_folder`, `get_config`, `save_config_field`, `get_levels` (121), `get_chapters` (15), `run_global_export`, `run_level_search`, `run_player_lookup`, `stop_leaderboard` — all three ops stream events via `_nwGlobalEvent` / `_nwLevelEvent` / `_nwPlayerEvent`
- **4 new pages**: Settings, GlobalExport, LevelSearch, PlayerLookup
- **main.jsx**: `steamStatus` + `outputFolder` lifted to App state; both loaded from bridge on mount; passed to child pages
- **shared.jsx Sidebar**: dynamic steam dot (ok/bad) + player name or "Not connected"; Settings nav item highlights correctly

### Bug fixes
- **Player Lookup "unknown" / 0 results**: Steam IDs (~7.6×10¹⁶) exceed `Number.MAX_SAFE_INTEGER`. Bridge was returning `steam_id` as a JSON number; JS silently garbled the last digits. Fixed: return as string in `get_steam_status` and `init_steam`.

### Output mode (display / csv / both)
- Added to all three leaderboard pages (Global Export, Level Search, Player Lookup)
- Folder field appears conditionally when csv or both selected; pre-fills from app-level `outputFolder` prop but tracks local override via `folderTouched`
- Bridge handles CSV writing server-side; `done` event includes `csv_path` shown in status line
- CSV filenames: `neon_white_top_{N}_entries.csv` (global), `{Level}_top{count}.csv` (level search), `{DisplayName}_{context}.csv` (player lookup)
- Player name sanitized for filename: alphanumeric + space/underscore/hyphen only

### Settings page
- Default output folder field + Browse (native folder dialog via `pick_folder`)
- Folder changes propagate instantly to all leaderboard pages via `onFolderChange` → App state (no restart required)
- DLL path saves on blur; folder saves on blur + Browse

### UI polish
- **Seg control width**: `align-self: flex-start` added to `.hifi .seg` — fixes oversized grey border extending past buttons (affected Output mode seg and Seed Finder mode seg)
- **Run Timer input window size**: S / M / L / XL / XXL presets (160 / 320 / 500 / 720 / 900px ≈ 6 / 12 / 20 / 28 / 36 rows); persisted to `localStorage`; "Input window size" label inline with buttons
- **Splits Updater**: added hint "The seed you want to adjust your splits to" under seed number field

## Known limitation noted
Steam closing while app is connected terminates the process — C-level access violation from unloaded DLL, not catchable in Python. Same behavior as the tkinter app.
