# 2026-05-10 — Community Guides: Watchlist / Watched markers

## What shipped

**Backend (`SteamScraper/webview_app/bridge.py`)**
- Added `guide_watchlist`, `guide_watched`, `guide_hide_watched`, `guide_watchlist_only` to `_DEFAULT_CONFIG`.
- Added `_CONFIG_LOCK` (threading.Lock) around all config I/O — `_load_config_raw` / `_save_config_raw` as internal helpers, public `_load_config` / `_save_config` for read-only callers.
- `save_config_field` now holds the lock across the full read-modify-write (no interleave window).
- New `save_config_fields(fields: dict)` — updates multiple keys atomically in one write. Used by Guides to save both watch arrays in a single call.
- `GuidesResponse` model gains a `loaded: bool` field so the frontend can distinguish "not loaded yet" from "loaded but empty".

**Frontend (`frontend/src/pages/Guides.jsx`)**
- `watchlist` + `watched` merged into single `watchState` object; `handleCycle` uses functional `setWatchState(prev => ...)` — rapid clicks no longer read stale closure state.
- Single `saveConfigFields(...)` call per click — both arrays written atomically.
- Filter toggles (`hideWatched`, `watchlistOnly`) now persist via config and hydrate on mount.
- `WatchCycleBtn`: ○ (dim) / ✓ (accent) / ✗ (red `#f87171`).
- `fetchFailed` now gated on `guidesLoaded` — "couldn't load" only shows if the sheet actually returned empty after loading, not during the race window.
- Polling loop added: if guides come back empty on mount, retries every second until `guides_loaded` flips.

**Frontend (`frontend/src/pages/RouteVideos.jsx`, `Ghosts.jsx`)**
- Added same polling pattern as `WorldRecordVods.jsx` — "Resources not loaded" dead-end replaced with "Loading resources…" that auto-populates once the background fetch finishes.

**`frontend/src/api.js`**
- New `saveConfigFields(fields)` export.
- New `getResourcesStatus` import used by Guides polling.

## Bugs fixed
- JSON corruption / duplicate keys from concurrent `saveConfigField` calls — fixed by lock + atomic write.
- "Resources not loaded" on first page visit (Route Videos, Ghosts) — fixed by polling.
- Guides sometimes showed load error on fast launch — fixed by `loaded` flag + polling.

## All test scenarios passed ✓
Cycle states · non-YouTube rows · Hide watched · Watchlist only · combined filters · persistence (marks + toggles) · accordion isolation · rapid clicking.
