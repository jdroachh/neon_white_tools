# Session 2026-05-06 — M2 Polish

## What landed

### Bug fixes
- **Splits Updater / Standardize NameError** — `reorder_splits` and `standardize_splits` both discarded the rush key (`_`) so `_compute_medals(..., key)` raised `NameError`. Fixed by capturing `key, count, names = _resolve_rush(...)`.
- **Seed Finder stop flicker** — in-flight progress events after stop were overwriting "Search stopped." status. Fixed: done event with `stopped=true` now explicitly sets "Search stopped." rather than skipping the update.
- **Seed Finder stop/restart** — `stop_finder()` now resets `_finder_running = False` immediately and tracks user-stop separately (`_finder_user_stopped`) so internal max-seeds stop doesn't suppress the done status update.
- **Community medal check order** — standard medals were checked before community medals; times faster than DEV never reached community check. Fixed: BD → Topaz → Sapphire → Amethyst → Emerald → DEV → ... 
- **BD / Topaz medals** — fetched from separate JSONs (`bd2.json`, `topaz2.json`); previous code used dead `comm[4]`/`comm[3]` indices that never existed.
- **Copy format** — tab-delimited clipboard output rendered with artefacts; switched to `Name: time  MEDAL`.

### New features
- **Run Timer redesign** — grid input (Level Name + Split Time per row), three load modes (standard/seed/manual), level name inputs lock in standard/seed modes.
- **Three copy buttons** — Times (bare times), Splits (Name: time), Medals (Name: time MEDAL).
- **Medal toggle** — global `showMedals` state in `main.jsx`; appears in page header after Calculate/Generate/Standardize on Run Timer, Splits Updater, and Standardize Splits. Persists across tab switches.
- **Medal support on Splits Updater / Standardize** — both gold and segment output panels show medal badges; bridge computes `gold_medals` + `segment_medals` in `reorder_splits` and `standardize_splits`.
- **Blood Diamond + Topaz** — two additional medal tiers fetched from DerelictJade NeonLite fork.
- **`get_standard_order` bridge method** — used by Run Timer standard mode.
