## Polish: Saved Profiles bugs ✓

Two issues found during testing:

1. **`[▾ Saved]` misaligned** — wrapper `<div>` lacked `display:"flex"`, so it didn't participate in flexbox alignment like the bare `<Btn>` siblings. Fixed.
2. **`[▾ Saved]` did nothing when clicked** — button was `disabled` when list was empty (user couldn't test it before adding profiles), and the `window.mousedown` click-outside listener was unreliable. Fixed: button always enabled; empty state shows "No saved profiles yet. Use ★ to save a Steam ID."; click-outside replaced with a fixed transparent backdrop div (z-index 199 behind dropdown at 200).
3. **Settings changes not reflected in Compare Players** — all WIRED_PAGES are always mounted (hidden via `display:none`), so ComparePlayers' useEffect ran only once at startup. Fixed by passing `visible={key === page}` from `main.jsx` and re-loading profiles in a `useEffect([visible])` whenever the tab becomes active.
