# 2026-05-11 — Beta Round 2: Welcome page + DLL finder (Phase A + B)

## What shipped

**New module: `SteamScraper/webview_app/dll_finder.py`**
- Pure functions: `read_steam_path()` (registry), `parse_library_folders()` (VDF regex, backslash-unescape), `search_for_dll()` (capped walk, 200 files / depth 5), `find_neon_white_dll()` (orchestrator returning `{found, path, steps}`).
- No tkinter/pywebview imports. Logger at debug level. Never called on startup.
- VDF fix: Valve's `.vdf` stores `\\`-escaped paths; `parse_library_folders` unescapes them so `os.path.join` works correctly.

**Bridge method: `find_steam_dll`** in `bridge.py` — thin wrapper, returns the dict from `find_neon_white_dll()`.

**API wrapper: `findSteamDll()`** in `frontend/src/api.js`.

**New page: `frontend/src/pages/Welcome.jsx`**
- Shown on first launch (config missing or `welcome_seen` falsy).
- "Find Steam DLL & Connect" button: calls `findSteamDll()` → `initSteam()` → on success, writes `dll_path` (+ optionally `welcome_seen`) and routes to `player_lookup`.
- "I'll set it up later" link: routes to Settings, no `welcome_seen` write unless checkbox is ticked.
- "Don't show again" checkbox (default unchecked): when ticked at dismiss time, writes `welcome_seen: true`.

**Modified: `frontend/src/main.jsx`** — landing-page selection:
- On mount: `Promise.all([getSteamStatus, getConfig])` → if `!cfg.welcome_seen` → Welcome; else if no `dll_path` or Steam not ready → Settings; else → `cfg.last_tab` (validated against `VALID_LAST_TABS`) or fallback `"lookup"`.
- `handleNav`: fires `saveConfigFields({ last_tab: key })` fire-and-forget on every nav (skips `welcome` and `settings`). Also clears `showWelcome` when navigating to any non-welcome page.
- `showWelcome` boolean gates the Welcome panel independently of `page` state.

**Modified: `frontend/src/pages/Settings.jsx`** — "Find DLL" button next to Browse:
- On click: `findSteamDll()` → if `found`, populates `dllPath`, saves to config, auto-connects via `initSteam`.
- Inline `findDllError` state shown below the field on failure.
- Tooltip: "Checks your Steam install path to locate the Neon White folder. No data is collected or sent."

## New config keys
- `welcome_seen: bool` — written only when user dismisses Welcome with checkbox ticked.
- `last_tab: str` — written on every successful navigation (non-welcome, non-settings).
