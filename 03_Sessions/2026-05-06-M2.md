# Session 2026-05-06 — M2

## Headline

M2 complete: Seed Finder + Run Timer wired end-to-end.

## What landed

### Backend (`webview_app/bridge.py`)

**New module-level helpers:**
- `_DISPLAY_TO_CODE` — pre-built display→code dict from `LEVELS` for O(1) medal lookup
- `_resolve_level_code(level_name, rush_key)` — ported from `neonwhite_app.py`
- `_get_medal(level_name, secs, rush_key)` — ported; checks STANDARD then COMMUNITY medals
- `_parse_time_to_secs(raw)`, `_format_secs(secs)` — ported from `tab_rush_timer.py`
- `_parse_level_names(raw, rush_key)` — ported from `tab_rush_finder.py`
- `_emit(event_data)` — pushes JSON to `window._nwFinderEvent` via `webview.windows[0].evaluate_js()`
- Community medals fetched in background daemon thread at import

**New `JsApi` methods:**
- `start_finder(rush_name, levels_str, depth, mode, max_seeds)` — validates inputs, starts manager thread; pushes `{type: "progress"|"result"|"done"|"error"}` events; returns `{ok, expected}`
- `stop_finder()` — signals stop event
- `load_timer_seed(rush_name, seed)` — decodes seed → list of level names for textarea prefill
- `calculate_timer(rush_name, seed, splits_text)` — fixed parser (trailing-token first, colon-split fallback, `.rstrip(":")` on name); returns `{ok, rows: [{name, cumulative, segment, segment_fmt, medal}]}`

**Timer parser fix:** Pre-existing bug where `"Movement: 17.442"` and `"Pummel Traversal 2:27.26"` both broke. Now parses trailing whitespace-separated token as time first, falling back to colon-split for compat.

### Frontend

- `frontend/src/pages/SeedFinder.jsx` — form (rush, levels, depth, mode, max seeds), progress bar, expandable seed cards showing full level order with targets highlighted in accent color
- `frontend/src/pages/RunTimer.jsx` — form with optional seed loader, splits textarea, two-panel output (segment times + medals | level order with cumulative times)
- `frontend/src/api.js` — 4 new wrappers: `startFinder`, `stopFinder`, `loadTimerSeed`, `calculateTimer`
- `frontend/src/main.jsx` — both pages added to `WIRED_PAGES` (keep-mounted pattern)

### Tests (`tests/test_bridge.py`)

11 new tests:
- Finder: bad levels, bad depth, valid start+stop, idle stop
- Timer: invalid seed, valid seed load (96 lines), empty input, bare times, name+time format, `"Name: time"` format, medal grade check
